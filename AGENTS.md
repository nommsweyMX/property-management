# Project instructions

## Effort and execution

The owner prefers **high reasoning effort** for this project. Use that setting when the execution environment exposes it. Do not claim to have changed the user's selected model or application controls when you cannot do so.

Implement, test and report concrete outcomes. A connector connection is not proof that writes work. Count a push as successful only after the remote commit is returned and read back. Do not keep the project idle while debugging a separate integration.

## Product

Property is the top-level entity. Support a small portfolio of one to four homes. Country/state/city/neighborhood/address remain property metadata. Keep optional area and equipment choices out of the way of fast phone-based reporting.

English and natural Mexican Spanish appropriate to Jalisco are first-class. Keep stable internal keys and preserve user-entered text when switching languages. Use per-property branding. The initial terracotta/green palette is a proposal, not a sampled house palette.

## Changes and collaboration

Read the remote default branch and existing code before changing anything. Another chat may be contributing. Do not force-push, replace unrelated files, or rewrite working code for cosmetic architecture preferences. Use a feature branch and pull request when the remote is initialized. Record nonessential improvements as issues or in the backlog.

## Privacy and safety

The target repository is public. Keep live property records, street addresses, contractor contacts, photos, invoices, tokens and invitation URLs out of source control. Examples must be visibly marked as examples. Credentials stay server-side. Authenticate and authorize every live data endpoint before enabling it. Never silently change a failed live save into a local-only success.

## Verification

Run `npm run check` and `npm test`. The optional offline UI smoke test uses mocked storage; never report it as proof of IndexedDB persistence, HTTPS deployment, Google authentication, service-worker offline behavior or a live Airtable write.
